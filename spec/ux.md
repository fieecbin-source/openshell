## 1. 设计原则与可度量目标

| 原则 | 具体表现 | 度量 |
|---|---|---|
| 会话优先 | 首屏 80% 面积用于会话树与终端；无营销页、无仪表盘首页 | 首次启动后 1 次点击即可连接最近会话 |
| 键盘优先 | 所有命令有快捷键或命令面板入口；焦点可见 | 100% 菜单项可在命令面板执行；Tab 遍历 ≤ 40 次 |
| 渐进披露 | 新建连接默认只显示 4 个必填项，高级项折叠 | 默认表单字段 ≤ 6；展开高级后 ≤ 20 |
| 状态可见 | 连接、传输、同步、监控均有持续状态指示 | 任一长任务 > 200 ms 有局部反馈 |
| 不打断 | 成功操作只用状态栏；破坏性操作才用模态 | 模态对话框仅用于确认/凭据/主机密钥/冲突 |
| 一致 | 同一操作在树、标签、侧栏、命令面板命名一致 | 文案键复用率 ≥ 90% |

### 2.2 会话树

| 元素 | 规格 |
|---|---|
| 行高 | 舒适 32 px / 紧凑 24 px |
| 层级缩进 | 每级 16 px，最大 8 级 |
| 节点内容 | 图标 16 px + 名称（省略号）+ 状态点（6 px）+ 可选标签色条 3 px |
| 状态点 | 灰=未连接；绿=就绪；黄=降级/重连中；红=失败；蓝=连接中 |
| 分组行 | 展开箭头 + 名称 + 子项计数（折叠时显示） |
| 顶部区 | 搜索框、收藏、最近、全部（三个可折叠区） |
| 底部区 | “新建连接”按钮 + 导入入口 |
| 空树 | 显示空状态（见 §9） |
| 搜索 | 200 ms 去抖，匹配名称/主机/用户名/标签；命中高亮；`Esc` 清空 |
| 多选 | Ctrl/Cmd+点击、Shift+范围选择；多选后可批量打开/移动/删除 |
| 拖拽 | 会话→分组（移动）、分组→分组（移动+防环）、会话→终端（打开新标签） |

### 2.3 标签与分屏

| 元素 | 规格 |
|---|---|
| 标签内容 | 状态点、名称（可重命名）、协议徽标（SSH/SFTP/TELNET/SERIAL/LOCAL）、关闭按钮 |
| 标签操作 | 单击激活、中键关闭、双击重命名、拖拽重排、拖出窗口（P2） |
| 溢出 | 左右滚动按钮 + 标签列表下拉（显示全部） |
| 分屏 | 2 分屏（水平/垂直）、4 分屏；分隔条 4 px，拖拽实时；双击分隔条均分 |
| 焦点 | 活动分屏边框 2 px 强调色；`Ctrl+Tab` 在分屏与标签间按视觉顺序移动 |
| 关闭 | 关闭有活动进程的标签需确认（可设置“总是确认/仅 SSH/从不”） |

### 2.4 侧栏

| 页签 | 内容 | 默认 |
|---|---|---|
| 文件（SFTP） | 路径面包屑、上级/刷新/跟随开关、文件列表、传输队列 | 连接后显示 |
| 监控 | CPU/内存/负载/网络/磁盘卡片 + 图表 | 用户开启后显示 |
| 会话详情（可选） | 连接信息、协商算法、转发状态 | 隐藏 |

侧栏行为：
- 可停靠左/右；可拖动宽度；可整体隐藏（Ctrl/Cmd+B）。
- 文件页签在未连接时显示空状态“选择会话以浏览文件”。
- 监控页签在采集失败时显示“监控不可用”与原因，不占满侧栏。
- 传输队列固定在文件页签底部，高度 120–240 px，可折叠。

### 2.5 状态栏

从左到右：连接状态 → 安全状态（已解锁/已锁定）→ 会话计数 → 同步状态（图标+相对时间）→ 当前会话指标（CPU/内存，可关）→ 编码/语言。

- 同步状态点击打开同步面板；连接状态点击打开连接诊断。
- 指标每 3 s 更新，悬停显示最近一次采样时间。
- 宽度不足时按优先级隐藏：指标 → 会话计数 → 安全状态文字（保留图标）。

### 2.6 命令面板

| 项 | 规格 |
|---|---|
| 唤起 | `Ctrl/Cmd+K`（终端聚焦时同样生效） |
| 列表 | 命令名 + 快捷键 + 分类；最近使用置顶（最多 5 条） |
| 搜索 | 前缀/模糊匹配，100 ms 内更新；支持拼音首字母（中文环境） |
| 执行 | Enter 执行；Shift+Enter 在后台执行（不关闭面板）；Esc 关闭 |
| 范围 | 所有菜单命令、会话切换（输入会话名可直接打开）、主题切换、同步操作 |
| 空结果 | “没有匹配的命令”，并提供“新建连接”固定入口 |

## 3. 关键流程

### 3.1 首次使用向导

| 步骤 | 界面 | 必填 | 可跳过 | 退出条件 |
|---|---|---|---|---|
| 1 语言与主题 | 语言（中文/English）、主题（浅/深/跟随系统） | 是（有默认） | 否 | 选择后“继续” |
| 2 保险库 | 创建主密码 + 确认；强度条与规则清单；“使用系统钥匙串”开关 | 是 | 否 | 两次输入一致且满足 SEC-001 |
| 3 导入会话 | 三个选项：从 OpenSSH config 导入 / 从文件导入 / 稍后再说 | 否 | 是 | 点击“完成” |

完成后：
- 若导入成功 → 打开会话树并选中第一个会话；
- 否则 → 显示空状态（§9 E-01），焦点在“新建连接”。

错误与边界：
- 主密码不一致：字段级错误，不弹模态。
- 主密码过弱：列出未满足的规则（实时）。
- 导入失败：留在第 3 步，显示错误摘要与“查看详情”，可跳过。
- 向导关闭（Esc）：提示“尚未创建保险库，退出将无法保存会话”，提供“返回/退出”。

验收：新用户从启动到主界面 ≤ 3 步；全程键盘可完成；向导只出现一次。

### 3.2 新建连接

入口：会话树底部按钮、`Ctrl/Cmd+N`、命令面板、空状态按钮。

表单结构（默认可见）：

| 字段 | 控件 | 默认 | 校验 |
|---|---|---|---|
| 名称 | 文本框 | 自动生成 `user@host` | ≤ 128；同组唯一 |
| 协议 | 分段控件（SSH/SFTP/Telnet/串口/本地） | SSH | 必选 |
| 主机 | 文本框 | 空 | 非空；支持 `host:port` 自动拆分 |
| 端口 | 数字 | 22（随协议） | 1–65535 |
| 用户名 | 文本框 | 上次使用 | SSH/Telnet 必填 |
| 认证 | 下拉（密码/公钥/键盘交互/agent） | 密码 | 依选择显示凭据/密钥选择器 |
| 分组 | 可搜索下拉 | 上次分组 | 可新建 |

高级（折叠）：跳板机、代理、keepalive、自动重连、编码、启动命令、工作目录、标签色、备注、转发规则。

底部操作：`测试连接`（次按钮）、`保存`（主按钮）、`保存并连接`（主按钮旁下拉）。

交互规则：
- 主机输入后 400 ms 去抖做格式校验，不自动发起连接。
- `测试连接` 显示四阶段进度（DNS/TCP/握手/认证）与耗时；失败显示阶段与错误码，不关闭表单。
- 未保存直接连接：允许，但关闭标签时提示“是否保存此连接”。
- 重复检测：保存时若 `(host,port,username)` 已存在，提示“已存在相同连接”，提供“打开已有/仍然创建”。

验收：3 次交互内完成创建；键盘 Tab 顺序符合视觉顺序；测试连接结果可定位到阶段。

### 3.3 连接中 / 失败 / 重连

状态与界面：

| 状态 | 终端区 | 标签 | 操作 |
|---|---|---|---|
| resolving | 显示“正在解析主机…”，6 s 超时 | 蓝点 + 旋转指示 | 取消 |
| tcp | “正在建立连接…”（显示地址:端口），10 s 超时 | 蓝点 | 取消 |
| handshake | “正在协商加密…”（可展开算法信息） | 蓝点 | 取消 |
| auth | “正在认证…”（密码/公钥/键盘交互类型） | 蓝点 | 取消；键盘交互弹表单 |
| ready | 终端可用，状态栏“已连接” | 绿点 | — |
| degraded | 顶部黄色条“连接不稳定，正在重试（2/7）”，终端只读 | 黄点 | 立即重试/断开 |
| closed | 终端保留内容并灰显，显示“连接已断开”+ 原因 + [重连] [复制诊断] | 红点 | 重连/关闭 |
| failed | 显示错误码、阶段、可读原因、建议 | 红点 | 重试/编辑连接 |

重连规则：
- 自动重连关闭（默认）：断线后只显示“重连”按钮，不自动发起。
- 自动重连开启：按 1/2/4/8/16/30 s 退避，最多 7 次；每次显示计数与下次时间；用户操作可取消。
- 重连成功后：保留终端历史并插入分隔行“—— 已重新连接 12:03:41 ——”；可选恢复工作目录。
- 断线原因分类：网络不可达、认证失败、主机密钥变更、服务器拒绝、空闲超时、用户取消。

验收：每次状态变化 ≤ 100 ms 反映到标签与状态栏；错误码可复制；取消 ≤ 200 ms 生效。

### 3.4 主机密钥校验

| 场景 | 对话框内容 | 按钮 |
|---|---|---|
| 首次连接 | 主机、端口、算法、SHA256 指纹（分组显示）、来源（首次） | `信任并连接`（主）、`取消`（次）、`查看详情` |
| 指纹变更 | 旧指纹（删除线）与新指纹并排、红色警示、变更时间 | `仅本次继续`（危险，需输入主机名确认）、`更新信任`（危险）、`取消`（默认焦点） |
| 已撤销 | 阻断说明 | `取消`（唯一） |

规则：
- 默认焦点在“取消”；`Enter` 不触发危险操作。
- 指纹支持复制；提供“与服务器管理员核对”的提示。
- “仅本次继续”不写入 KnownHost；断开后再次连接会重新提示。
- 对话框不可通过点击遮罩关闭。

### 3.5 SFTP 上传/下载

上传（本地→远端）：

1. 侧栏定位目标目录（或跟随终端）。
2. 拖入文件/文件夹（或点击“上传”选择）。
3. 若存在同名：弹出覆盖对话框（覆盖/跳过/重命名/全部应用），显示大小与修改时间差异。
4. 任务进入队列，底部显示进度、速率、剩余时间。
5. 完成后状态栏“已上传 3 个文件（12.4 MB）”，失败项标红并提供重试。

下载（远端→本地）：

1. 多选文件/文件夹。
2. 选择本地目标（默认上次目录；可选“每次询问”）。
3. 同名冲突同上。
4. 队列显示进度；可暂停/继续/取消。
5. 完成后提供“打开所在文件夹”。

边界：
- 无权限：错误“权限不足（550）”，提供“尝试提升权限/修改权限”（若服务器支持）。
- 磁盘满：暂停队列并提示，不丢任务。
- 断线：任务标记“已暂停（连接断开）”，重连后可继续（支持断点续传时从偏移继续）。
- 超大目录：先扫描并显示文件数与预计大小，超过 10,000 项需确认。

验收：5 个文件上传成功率 100%（测试环境）；冲突四选项均生效；断线重连后续传成功。

### 3.6 端口转发配置

入口：工具菜单、命令面板、侧栏“转发”区（P1）、会话编辑高级页。

表单：

| 字段 | 控件 | 默认 | 校验/提示 |
|---|---|---|---|
| 名称 | 文本框 | `本地 8080 → db:5432` | 必填 |
| 类型 | 分段（本地/远程/动态） | 本地 | 切换时字段联动 |
| 绑定地址 | 下拉（127.0.0.1 / ::1 / 0.0.0.0 / 自定义） | 127.0.0.1 | 通配地址需确认 |
| 绑定端口 | 数字 | 空 | 1–65535；启动前检测占用 |
| 目标主机/端口 | 文本框/数字 | 空 | 本地/远程必填 |
| 所属会话 | 下拉 | 当前会话 | 必填（独立规则 P2） |
| 随会话启动 | 开关 | 关 | — |
| 自动重连 | 开关 | 开 | — |
| SOCKS 认证 | 无/用户名密码 | 无 | 仅动态 |

流程：
1. 填写 → “测试”检查本地端口占用与 SSH 目标可达性（不实际监听或短暂监听）。
2. 保存 → 列表新增，状态“已停止”。
3. 启动 → 状态“监听中”；失败显示错误码与原因（端口占用/权限不足/远端拒绝）。
4. 关闭会话 → 绑定规则停止；独立规则保持。

安全提示：
- 绑定 `0.0.0.0`/`::`：红色提示“同一网络中的其他设备可访问此端口”，需勾选确认。
- 远程转发：提示“远端服务器将监听该端口，可能对其他用户可见”。
- 动态转发：提示“本机应用需配置 SOCKS5 代理”。

验收：创建 3 种规则各 1 条并启动成功；端口冲突提示准确；通配绑定必须确认。

### 3.7 远程编辑与冲突

1. 双击远端文本文件 → 下载到缓存（显示进度）→ 用内置编辑器或系统默认编辑器打开。
2. 编辑保存 → 客户端检测变更 → 比较远端 mtime/size/hash：
   - 无变化：直接回传，状态栏“已保存到远端”。
   - 有变化：弹出冲突对话框（保留本地/保留远端/另存副本/打开比较）。
3. 回传失败：保留本地副本，提示路径与错误码，可重试。
4. 二进制/超大文件（> 8 MB 或扩展名在黑名单）：不自动打开，提示“下载到本地/用其他程序打开”。

冲突对话框：
- 并排显示本地/远端大小、修改时间、哈希前 8 位。
- 默认焦点“打开比较”；危险操作“覆盖远端”需二次确认。
- 选择“另存副本”后本地文件重命名为 `<name>.local-<timestamp>.<ext>`。

### 3.8 同步冲突

入口：状态栏同步图标（带冲突计数）→ 同步面板 → 冲突列表。

列表字段：记录类型、名称（解密后显示）、本地修改时间、远端修改时间、来源设备、冲突类型。

操作：
| 操作 | 结果 |
|---|---|
| 保留本地 | 以服务端版本为 base 提交本地内容，生成新版本 |
| 保留远端 | 丢弃本地修改（需确认），拉取远端 |
| 逐字段合并 | 打开字段对比（名称/主机/端口/用户名/凭据引用等），保存后提交 |
| 另存为副本 | 本地内容生成新记录（名称加“（冲突副本）”），远端保留 |
| 稍后处理 | 保留在冲突列表，状态栏持续显示计数 |

规则：
- 冲突不阻断其他同步；不同记录的变更继续同步。
- 任何选项都不得静默删除数据；删除冲突时“保留副本”为默认建议。
- 批量操作（全部保留本地/全部保留远端）需显示将影响的记录数并确认。
- 冲突解决后 2 s 内状态更新。

验收：构造 4 类冲突（同字段、删除 vs 修改、修改 vs 删除、双方新建）逐一走通；无数据丢失；状态栏计数正确。

### 3.9 导入向导

| 步骤 | 内容 |
|---|---|
| 1 选择来源 | OpenSSH config / JSON / CSV / 加密包（.osvault） |
| 2 配置 | 文件选择、编码、CSV 列映射（仅 CSV）、导入范围 |
| 3 预览 | 新增/更新/跳过/警告计数；冲突列表；不支持项列表 |
| 4 执行 | 进度条；完成后汇总；失败可导出报告 |

规则：
- 预览必须可滚动查看每一条冲突，支持搜索。
- “覆盖”与“保留两者”互斥选择；可逐项改。
- 执行是事务性的：失败不产生部分数据（IMP-002）。
- 完成页提供“打开导入的会话分组”。

### 3.10 锁定与解锁

- 锁定：启动时若已启用主密码则进入锁定页；空闲超时、系统锁屏、手动 `Ctrl/Cmd+L` 也会锁定。
- 锁定页：应用名、当前保险库名、密码输入、`解锁`、`使用系统钥匙串解锁`（若启用）、`退出`。
- 错误密码：字段级错误 + 剩余尝试次数（5 次后冷却 30 s，递增）。
- 解锁后恢复上次布局（不自动重连）。
- 锁定期间菜单仅保留“退出/关于/解锁”，不暴露会话信息。

- 同步输入模式：顶部 32 px 高亮条（强调色背景）显示“同步输入：3 个目标”，并列出目标标签；点击可编辑目标。
- 输入广播：仅将键盘输入广播到目标；粘贴需使用专用快捷键或在模式内确认。
- 危险命令：发送前检测（`rm -rf`、`dd`、`mkfs`、`shutdown`、`reboot`、`chmod -R`、重定向到块设备等），弹出确认，列出目标数量与命令全文前 200 字符。
- 退出模式：`Esc` 或再次按快捷键；退出后输入仅发送到当前标签。
- 目标关闭/断线：从目标集合移除并提示，不阻塞其余目标。

## 8. 状态规范

### 8.1 空状态（Empty）

| ID | 场景 | 标题（zh / en） | 说明 | 行动（≤2） |
|---|---|---|---|---|
| E-01 | 会话树为空 | 还没有连接 / No connections yet | 创建第一个 SSH 连接，或从现有配置导入。 | 新建连接；导入 |
| E-02 | 搜索结果为空 | 没有匹配项 / No matches | 尝试更短的关键词，或清除筛选。 | 清除筛选 |
| E-03 | 未连接时的文件侧栏 | 选择会话以浏览文件 / Select a session to browse files | 文件面板会复用当前终端的连接。 | 打开最近会话 |
| E-04 | 监控无数据 | 监控尚未开始 / Monitoring hasn't started | 连接后启用监控，或检查远端是否支持。 | 启用监控；查看原因 |
| E-05 | 同步未启用 | 同步已关闭 / Sync is off | 配置你自己的服务器地址后启用端到端加密同步。 | 配置服务器 |
| E-06 | 传输队列为空 | 暂无传输任务 / No transfers | 将文件拖到列表即可上传或下载。 | — |
| E-07 | 转发列表为空 | 还没有转发规则 / No forwarding rules | 创建本地、远程或动态转发。 | 新建规则 |
| E-08 | 冲突为空 | 没有需要处理的冲突 / No conflicts | 所有变更已合并。 | — |

规范：
- 图标 32 px 线性图；标题 16 px；说明 13 px，最多 2 行。
- 行动按钮最多 2 个，主按钮 1 个；键盘焦点默认在主按钮（E-02 在输入框）。
- 不显示插画大图，保持信息密度。

### 8.2 错误状态（Error）

| 层级 | 使用场景 | 必含元素 | 行为 |
|---|---|---|---|
| 字段级 | 表单校验 | 字段高亮 + 说明 + 修正建议 | 不弹窗；焦点移至首个错误 |
| 内联 | 面板/列表加载失败 | 图标 + 一句话 + 错误码 + [重试] + [复制诊断] | 保留已有内容；可折叠详情 |
| 模态 | 阻塞性错误（无法继续） | 标题 + 原因 + 错误码 + 操作（重试/取消/查看详情） | 默认焦点“取消”；Esc 关闭（若可恢复） |
| 全局 | 应用级崩溃/无法启动 | 恢复选项（安全模式/导出诊断/退出） | 记录脱敏日志 |

错误文案规则：
- 结构 = 发生了什么 + 影响 + 下一步；不使用“未知错误”作为唯一信息。
- 必须显示可复制的错误码（如 `SSH_AUTH_FAILED`）。
- 不显示堆栈、路径中的用户名、主机名（可显示脱敏形式）。
- 网络类错误显示重试按钮与自动重试倒计时。

### 8.3 加载状态（Loading）

| 时长 | 反馈 | 示例 |
|---|---|---|
| < 200 ms | 无显式加载（避免闪烁） | 切换标签 |
| 200–500 ms | 局部 spinner（16 px）+ 文本 | 目录刷新 |
| > 500 ms | 骨架屏或进度条 + 已用时间 | 首次加载会话树、导入预览 |
| > 5 s | 增加“取消”与“在后台继续”（若支持） | 大文件传输、同步 |
| 未知时长 | 不确定进度条 + 当前阶段文本 | 连接握手 |

规则：
- 骨架屏形状与最终内容一致；不使用闪烁动画（尊重减少动效）。
- 加载中保留可交互部分（如可切换标签），不整屏遮罩。
- 失败后不保留无限 spinner；转为错误状态。
