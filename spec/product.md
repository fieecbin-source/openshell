## 0. 术语

| 术语 | 定义 |
|---|---|
| 保险库（Vault） | 客户端本地加密数据集合，包含会话、分组、凭据、密钥、片段、转发规则、设置 |
| 主密码 | 用户设定的保险库解锁口令，只在客户端内存中使用，从不上传 |
| 会话（Session） | 一条可复用的连接配置（SSH/SFTP/Telnet/串口/本地 Shell） |
| 标签（Tab） | 一个运行中的终端或文件视图实例 |
| 同步记录（Record） | 同步的最小单元（一条会话、一个分组、一条片段等），有稳定 ID 与版本号 |
| 光标（Cursor） | 服务端单调递增的提交序号，客户端用它增量拉取 |
| 墓碑（Tombstone） | record_id + 删除版本，用于把“删除”传播到其他设备 |
| 目标（Target） | 更新分发的平台/架构标识，如 `windows-x86_64`、`macos-universal`、`linux-arm64` |

优先级定义：**P0** = 首版必须可用且通过验收；**P1** = 首版应交付，允许在 M5 前补齐；**P2** = 首版后增强，接口与数据模型需预留。

## 1. 产品定位与目标用户

### 1.1 定位

一款轻量、跨平台（Windows / macOS / Linux）、键盘优先的 SSH/终端工作台：以“会话树 → 标签 → 侧栏文件/监控”的连续工作流为核心，内置零部署的服务器监控、端口转发与端到端加密同步；需要联网的能力由用户自建服务端提供。

### 1.2 目标用户

| 用户 | 典型任务 | 关键诉求 | 成功判据 |
|---|---|---|---|
| 运维工程师 | 同时维护多台 Linux 主机、排障、传文件 | 多会话并行、快速重连、同步输入、监控一眼可见 | 日常 3 台以上并发操作无需切换工具 |
| 后端开发者 | 登录测试/生产机看日志、改配置 | 启动快、终端舒适、SFTP 与终端目录联动 | 冷启动到可用 ≤ 1.5 s，登录后侧栏即定位同一目录 |
| 嵌入式/网络工程师 | 串口设备、跳板机后内网主机、临时端口转发 | 串口可用、多级跳板、转发可视化 | 串口与 5 级跳板链路均有自动化测试 |

非目标用户：需要图形远程桌面（RDP/VNC）、需要团队协作共享会话、需要浏览器或 X11 应用的人群（见 §2.3）。

### 1.3 设计原则

1. **会话为中心**：首屏即会话树，任何功能最多两次点击/一次命令面板可达。
2. **单连接多通道**：终端、SFTP、监控、端口转发复用同一 SSH 连接与认证，不重复登录。
3. **零 agent**：监控只依赖远端标准命令，不安装任何服务端组件。
4. **安全默认**：默认校验主机密钥、默认不保存明文凭据、默认不联网（同步与更新均需显式开启或手动触发）。
5. **键盘全覆盖**：所有功能都有快捷键或命令面板入口，鼠标不是必需。
6. **可自建**：同步、更新、中继全部指向用户配置的地址，不硬编码任何第三方服务。

### 2.3 明确不做清单

| 不做项 | 理由 | 约束 |
|---|---|---|
| 授权/激活/试用/付费墙/账号体系仿制 | 合规范畴外 | 永不实现 |
| 复刻任何第三方私有协议、加密方案、接口字段 | 洁净室原则 | 同步/更新/中继均为自设计接口 |
| 内嵌服务器（TFTP/FTP/HTTP/Telnet/NFS/VNC 服务端） | 攻击面大、与定位无关 | 不实现 |
| 终端小游戏、屏保、崩溃测试菜单、包管理器 | 与“轻量”冲突 | 不实现 |
| X11 服务器与 XDMCP、内嵌浏览器、对象存储会话 | 跨平台成本高、体积大 | M5 之后也不在路线图 |
| 网络扫描、端口扫描、抓包、Wake-on-LAN | 隐私敏感、需额外驱动/权限 | 不实现 |
| 团队共享会话目录 | 用端到端加密同步替代 | 不实现 |
| 明文 FTP / Rsh / XDMCP 会话 | 协议不安全 | 不实现；Telnet 仅在用户显式创建时提示风险 |
| 运行时插件机制（第三方二进制扩展） | 攻击面与签名链复杂 | 不做；主题/配色以纯数据文件扩展 |
| 服务端明文存储任何保险库内容 | E2EE 承诺 | 服务端只存不透明密文与元数据 |
| 默认遥测/崩溃上传 | 隐私 | 默认关闭，需用户逐次同意 |

## 4. 功能取舍说明

以下为基于匿名化分析结论与目标定位的取舍，不针对任何具体产品。

### 4.1 保留（因为直接提升主流程效率）

| 设计 | 为什么保留 | 我们的改进 |
|---|---|---|
| 会话树 + 最近 + 收藏 + 搜索 | 降低重复输入，是最高频入口 | 虚拟列表支持 1000 条，搜索 200 ms 内出结果 |
| 单 SSH 连接多通道复用（终端/SFTP/监控/转发） | 减少认证次数，文件与终端目录天然同源 | 明确通道故障隔离：SFTP 断开不影响终端 |
| 登录即得文件侧栏 + 跟随终端目录 | 消除“手动找目录”的重复劳动 | 优先 OSC 7，轮询作为回退，并限制频率 |
| 无 agent 监控 | 零部署，适配大多数 Linux | Profile 化探测、采样可调、失败降级、开销上限 |
| 三态端口转发 + 持久化 | 运维高频需求 | 端口占用检测、健康检查、自动重连、暴露提示 |
| 片段/命令历史/命令输入栏 | 批量操作效率 | 目标集合显式化、危险命令确认、视觉模式条 |
| 逐记录版本 + 删除墓碑 + 本地备份 | 多设备合并与可回滚的基础 | 端到端加密、显式冲突 UI、快照回滚 |
| 默认无遥测、手动更新检查 | 隐私与可预测网络行为 | 签名清单、灰度、可撤销、失败回滚 |

### 4.2 砍掉（因为收益低于维护/安全/体积成本）

| 砍掉项 | 判断依据 |
|---|---|
| 内嵌多种网络服务器、X11 服务器、内嵌浏览器、终端游戏 | 与本产品主线弱相关，显著增大体积与攻击面 |
| 自带完整运行时（JRE/独立浏览器内核） | 与 ≤ 25 MB 安装包目标冲突 |
| 应用字符串加密/反射式解密 | 不构成安全边界，破坏可维护性与可审计性 |
| 固定且不可配置的同步服务器、无签名“下载即执行”更新 | 不可自建、供应链风险高 |
| 依赖系统驱动的抓包/扫描能力 | 需要管理员权限，跨平台成本高，隐私敏感 |
| 28 MB 级离线地理库 | 对核心工作流价值低 |
| 明文 FTP/Rsh/XDMCP | 协议本身不安全 |

### 4.3 做得更好的具体点

| 主题 | 我们的设计选择 | 可验收结果 |
|---|---|---|
| 凭据保护 | 主密码 → Argon2id → 包裹随机 vault key → 每记录 AEAD；秘密与元数据分离 | SEC-002~004、SEC-016 |
| 同步 | 自建 API、E2EE、记录级乐观锁、显式冲突副本、快照回滚 | SYNC-004~010、`sync-api.md` |
| 终端 | xterm.js + WebGL、真彩色、搜索、链接、日志、背压 | TERM-004~010、TERM-020 |
| 文件 | 队列、断点续传、限速、冲突检测、缓存上限 | FILE-005~011、FILE-016 |
| 监控 | 可配置 profile、采样退避、非 Linux 降级、开销上限 | MON-003~005、MON-008 |
| 弱网 | 指数退避重连、降级提示、离线同步队列 | SESS-010、SYNC-011 |
| 导入 | 预览 + 冲突策略 + 事务性 + 可扩展映射 | IMP-001~008 |
| 会话恢复 | 保存布局与工作目录，明确“非热恢复” | SESS-011 |
