# 洁净室规格书：SFTP 视图与传输系统规格（spec/sftp-view.md）

> 依据目标：[docs/REQ-2/goal_serial_sftp_view.md](../docs/REQ-2/goal_serial_sftp_view.md) 第 7.3 节与第 9 节  
> 责任角色：Spec-Writer（洁净室隔离层）  
> 适用对象：Core-Dev、UI-Dev、QA、Security-Reviewer  
> 隔离合规：禁止引用竞品反编译代码、图标与文案。基于 POSIX/IETF SFTP 协议规范（RFC 913 / draft-ietf-secsh-filexfer）定义现代化纯净交互与数据契约。

---

## 1. 浏览与文件导航规格

### 1.1 地址栏与面包屑导航（Breadcrumb & Address Bar）

1. **双态地址栏组件**：
   - **面包屑状态（默认）**：将当前绝对路径按 `/` 分割为级联面包屑按钮（如 `/` > `var` > `log` > `nginx`）；点击任意一级直接跳转到该级目录；悬浮在某一级上时，支持点击右侧小下拉箭头展开该级子目录快捷列表。
   - **可编辑文本状态**：点击地址栏空白处或按下快捷键 `Ctrl+L`（macOS 为 `Cmd+L`），立即切换为标准输入框（全选当前路径），支持用户直接输入或粘贴绝对路径（如 `/etc/systemd/system/`），按 `Enter` 触发加载跳转，按 `Esc` 恢复面包屑。
2. **导航动作按钮组**：
   - **后退（Back）** / **前进（Forward）**：维护当前视图卡的目录浏览历史栈（栈深上限 50）。
   - **返回上级（Up）**：直接导航至 `..` 父目录（根目录 `/` 时禁用）。
   - **刷新（Refresh）**：清除本地当前目录缓存，向远端重新读取最新条目。
   - **主目录（Home）**：一键直达当前登录用户主目录（`~`）。
   - **书签与最近访问（Bookmarks & Recents）**：下拉菜单提供已收藏的常用服务器路径与最近访问的 10 个目录。
   - **隐藏文件开关**：工具栏提供眼睛图标开关，一键切换显示/隐藏以 `.` 开头的点文件。
   - **快速过滤搜索框**：输入关键字即时对当前列表条目进行客户端模糊匹配，支持高亮匹配字符。

### 1.2 文件列表与虚拟视口滚动（Virtual Scroll）

1. **列模型与展示规范**：

| 列字段 | 显示格式 | 排序规则 | 默认宽度 |
|---|---|---|---|
| **名称（Name）** | 文件/文件夹图标 + 名称字符串；符号链接显示小斜箭头并在悬停 Tooltip 中展示目标路径（如 `-> /lib/systemd`） | 字典序（A-Z / Z-A），**文件夹始终默认置顶**（可配置） | 自适应（主列，最小 220px） |
| **大小（Size）** | 智能单位格式化：`B`, `KiB`, `MiB`, `GiB`, `TiB`（如 `14.2 MiB`）；文件夹显示为 `-` 或项目数（如 `12 项`） | 按真实原始字节数大小数值排序 | 100px |
| **类型（Type）** | `文件夹`, `常规文件`, `符号链接`, `块设备`, `字符设备`, `Socket`, `FIFO 管道` | 按类型分类排序 | 90px |
| **修改时间（Mtime）** | 标准本地化时间（`YYYY-MM-DD HH:mm:ss`） | 按 UNIX 时间戳绝对值排序 | 150px |
| **权限（Perms）** | 标准 POSIX 字符（如 `drwxr-xr-x`, `-rw-r--r--`）或八进制（如 `0755`, `0644`） | 按权限数值排序 | 100px |
| **所有者 / 属组** | `UID:GID` 或已解析的用户名与组名（如 `root / root`, `www-data`） | 按字母排序 | 110px |

2. **列定制能力**：
   - 表头支持拖拽调整列宽；
   - 表头右键菜单支持勾选/取消勾选任意列（除名称列外）；
   - 点击表头在升序、降序与恢复默认之间循环切换。
3. **海量条目虚拟滚动（Virtual Scroll Specification）**：
   - 当目录下包含 10,000+ 文件条目时，**DOM 节点严禁线性渲染**；
   - 必须采用虚拟视口滚动技术（基于 `@tanstack/react-virtual`）；
   - DOM 树内永久仅保持可视视口范围内约 25~35 个节点；
   - 保证在 10,000 级文件大目录下，滚动帧率稳定在 60 fps，内存消耗恒定在 30MB 以内，无任何白屏掉帧。

### 1.3 键盘导航与多选规范

- `Shift + 鼠标单击`：连续区间选择；
- `Ctrl + 鼠标单击`（macOS 为 `Cmd + 单击`）：离散多选；
- `Ctrl + A`：全选当前目录下所有文件；
- 键盘操作：方向键上下移动焦点选区；`Enter` 键进入选中目录；`Delete` 键触发删除确认；`F2` 键触发重命名；`F5` 键刷新。

## 2. 文件系统操作规格

### 2.1 基础文件操作契约

1. **新建文件 / 新建文件夹**：
   - 工具栏按钮与右键上下文菜单提供入口；
   - 列表中就地插入一个高亮带焦点输入框（或弹出轻量模态框）；
   - 校验：文件名禁止包含 `/`、`\0` 及全空字符；创建成功后自动选中该新项目。
2. **重命名（Rename）**：
   - 选中项目按 `F2` 或右键“重命名”；
   - 就地变为输入框，默认仅选中文件名（不含扩展名）；
   - 按 `Enter` 提交，按 `Esc` 取消。
3. **删除操作（Delete with Strong Safeguards）**：
   - 选定 1 个或多个文件/目录按 `Delete` 或点击右键“删除”；
   - **安全阻断模态框**：
     - 若包含文件夹：显著标黄/红高危警告图标，文字注明：“选中的项目中包含 X 个文件夹。此操作将**递归永久删除**远程服务器上的所有内容，不可撤销！”；
     - 需用户在模态框中明确点击“确认删除”；
     - 删除根目录 `/`、系统关键目录 `/etc`, `/usr`, `/var`, `/bin` 等一律予以额外强警告确认。
4. **权限修改（Chmod Modal）**：
   - 选中文件/文件夹右键“修改权限”；
   - 弹出专业 POSIX 权限设置模态框：
     - 包含 3x3 权限网格（所有者、用户组、其他人的读 `r`、写 `w`、执行 `x` 勾选框）；
     - 提供八进制数值即时联动输入框（如 `0755`, `0644`），勾选状态与八进制数值双向同步；
     - 对于文件夹，额外提供“递归应用到所有子文件与子目录（-R）”复选框。
5. **文件属性查看（Properties）**：
   - 展示绝对路径、文件大小、创建/修改/访问时间、链接目标真实路径、文件哈希计算（可选触发）。

### 2.2 远程临时轻量编辑与自动回传（Remote Quick Editor）

1. **触发方式**：
   - 双击文本类文件（如 `.conf`, `.sh`, `.json`, `.py`, `.yaml`, `.txt`, `.log`）或右键选择“在线编辑”；
   - 核心层将文件安全拉取至本地沙盒临时目录（`AppData/openshell/temp_edits/{conn_id}/{hash}`）。
2. **编辑与冲突感知**：
   - 弹出内置轻量代码编辑器（带行号、语法高亮与查找替换）；
   - 用户按下 `Ctrl + S`（或点击保存按钮）：
     - 编辑器先发起远端文件元数据比对（`Mtime` 与 `Size`）；
     - 若自打开以来远端未被修改：直接流式回传覆盖更新；
     - 若检测到远端已被他人修改：弹出冲突警告：“远端文件已变更，是否强行覆盖或保存为新文件？”。
3. **临时文件清理**：
   - 视图卡关闭或 OpenShell 退出时，自动全量清理本会话创建的临时文件，不留垃圾。

## 3. 上传与下载（传输引擎规格）

### 3.1 交互触发路径

1. **原生拖拽上传（Drag-and-Drop Upload）**：
   - 用户从操作系统（Windows 资源管理器 / macOS Finder / Linux 桌面）拖拽一个或多个文件/文件夹悬停在 SFTP 文件列表或面包屑任意节点上；
   - 悬浮区域高亮呈现虚线框与“释放以开始上传到当前目录”视觉提示；
   - 松开鼠标后立即在核心层解析本地文件路径树，生成传输任务并入队。
2. **按钮与菜单上传**：
   - 顶部工具栏“上传”下拉菜单提供：“上传文件…”（唤起系统文件选择框）、“上传文件夹…”（唤起系统目录选择框）。
3. **下载触发**：
   - 选定 1 个或多个文件/目录，右键选择“下载”；
   - 若用户在首选项中配置了“默认下载目录”：直接静默入队下载并弹出系统小提示通知；
   - 若未配置或长按 `Shift + 下载`：唤起系统“选择保存目录”对话框。

### 3.2 传输队列与任务模型

1. **任务实体（`TransferTask`）**：

| 属性 | 类型 | 描述 |
|---|---|---|
| `id` | TaskId (UUID/ULID) | 全局任务唯一标识 |
| `card_id` | CardId | 归属的视图卡 ID（与视图卡紧密绑定） |
| `direction` | Enum | `Upload`（上传） / `Download`（下载） |
| `local_path` | PathBuf | 本地绝对路径 |
| `remote_path` | String | 远程绝对路径 |
| `total_bytes` | u64 | 文件总字节数（文件夹为子项总字节数） |
| `transferred_bytes`| u64 | 当前已完成传输的字节数 |
| `state` | Enum | `Queued`（排队）, `Running`（传输中）, `Paused`（暂停）, `Completed`（已完成）, `Failed`（失败）, `Cancelled`（已取消） |
| `speed_bps` | u64 | 瞬时传输速率（字节/秒，基于 1 秒滑动窗口平滑计算） |
| `error_message` | Option<String> | 失败原因（权限不足/磁盘满/断线/路径不存在） |

2. **状态机与操作控制**：
   - **排队与调度**：采用优先级与先进先出队列；支持配置**全局/单卡并发传输数**（默认 `3`，可配置 1~8）；超出并发数的任务保持 `Queued`。
   - **控制按钮**：每个任务提供 `暂停`、`继续`、`重试`、`取消`；队列顶栏提供 `全部暂停`、`全部继续`、`全部取消`、`清空已完成`。
   - **文件夹传输策略**：“先扫描建立目录树，再批量流水线分块传输”，提供文件夹总进度与当前单文件进度的嵌套反馈。

### 3.3 断点续传（Resumable Transfer Specification）

1. **核心机制**：
   - 在向目标写入数据前，传输引擎先查询对端已存在同名目标文件的大小（`existing_size`）与修改时间；
   - 若满足断点续传条件：
     - 上传时：以 `OpenOptions::write(true).append(false)` 打开远端文件，直接调用 `seek(SeekFrom::Start(existing_size))` 定位至偏移量，从本地文件的 `existing_size` 偏移处继续流式分块读取并写入；
     - 下载时：本地文件以追加/指定偏移模式打开，向 SFTP 发送指定 `offset` 的分块读取请求；
   - 界面上进度条立即填充至已完成比例，并标明“已断点续传”。

### 3.4 冲突解决策略（Conflict Resolution Policy）

当上传或下载检测到目标路径已存在同名文件且未处于续传状态时，触发冲突处理：
1. **全局预设策略**：首选项中可预置默认行为：`询问（Prompt）`、`覆盖（Overwrite）`、`跳过（Skip）`、`自动重命名（Rename）`。
2. **交互式冲突询问弹窗**：
   - 弹窗直观对比双方信息：
     - 源文件：大小、最后修改时间；
     - 目标文件：大小、最后修改时间（标明较新/较旧）；
   - 提供动作选项：
     - `覆盖（Overwrite）`：抹掉目标文件并从头传输；
     - `断点续传（Resume）`：从已存在文件末尾继续传输；
     - `跳过（Skip）`：放弃当前文件传输并标记为已跳过；
     - `保留两者（Auto-Rename）`：自动在目标文件名追加时间戳或序号（如 `file(1).txt`）；
   - 包含复选框：“**应用到后续所有冲突（Apply to all remaining conflicts）**”。

### 3.5 1GB+ 级大文件流式传输规格（Zero Full-Buffering）

1. **流式分块 I/O 契约**：
   - 核心层传输引擎**绝对禁止**将 1GB 级的大文件整体读入内存中；
   - 传输全程采用严格的 **固定分块流式流水线（Streaming Chunk Pipeline）**，单块大小固定为 `64 KiB` ~ `256 KiB`；
   - 后端在传输过程中常驻内存消耗必须保持稳定（单传输任务内存开销 ≤ 8 MB），即使传输 50GB 大镜像文件也绝不上涨；
   - 传输完毕自动执行 SHA-256 或大小校验（若对端支持相关 SFTP 扩展）。

## 4. 安全防护与审计规格

1. **路径穿越防护（Anti-Path Traversal）**：
   - 本地与远程路径在拼接与操作前，必须经过标准安全规范化处理（`normalize_path`）；
   - 严禁允许路径中包含未经处理的 `../` 逃逸出用户指定的目标基准目录；
   - 符号链接解析时，校验是否指向根外部高危路径，若越权应予以拦截或警告。
2. **本地下载沙盒保护**：
   - 下载到本地时，禁止直接覆盖操作系统核心系统目录（如 Windows 的 `C:\Windows\System32`、Linux 的 `/bin`, `/lib`）；
   - 默认下载保存路径必须为用户操作系统专属下载目录（`Downloads`）或工作空间沙盒目录。
3. **凭据与日志脱敏（Zero Plaintext Credentials）**：
   - SFTP 子系统与传输日志中，严禁输出任何口令、私钥明文或临时认证 Token；
   - 错误日志中的远程绝对路径在安全审计等级高时做主目录掩码化。
