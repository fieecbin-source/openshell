# 决策记录（docs/decisions.md）

> 记录灰区决策、方案变更、超 3 轮未修好的问题与降级方案。新条目追加在末尾。

## D-001 目标文档唯一来源

- 日期：2026-10-21
- 决策：以 `docs/openshell_design_prompt.md` 作为本项目唯一目标文档；用户提及的 `goal_prompt.md` 在本仓库不存在，视为同一文档。
- 理由：目录内仅有该文件，内容与用户描述一致。

## D-002 洁净室隔离落地方式

- 日期：2026-10-21
- 决策：
  1. `analysis/` 永久加入 `.gitignore`，任何反编译产物、字符串表、抓包、截图不进入版本库。
  2. `spec/` 与 `docs/` 是实现 agent 的唯一输入；派发 Core-Dev / UI-Dev / Server-Dev 的任务描述中不引用 `analysis/`。
  3. 分析文档只写"行为/设计规格"，不摘抄对方文案、图标、配色、字符串。
- 理由：遵守目标文档第 1 节硬性约束，优先级最高。

## D-003 分析工具的合规边界

- 日期：2026-10-21
- 决策：不分析许可证/激活/付费墙相关代码路径；不做反调试绕过；不对官方服务器做任何压测或越权探测。网络观察仅限用户本人账号，且只记录脱敏后的接口语义。
- 理由：目标文档 1.2 / 1.3。

## D-004 目录骨架

- 日期：2026-10-21
- 决策：单仓多包：`apps/desktop`（Tauri 应用）、`crates/*`（Rust 核心库）、`server/`（axum 服务端）、`deploy/`、`tests/`、`spec/`、`docs/`。
- 理由：满足目标文档第 6 节，便于以后复用核心 crate 做 CLI。
