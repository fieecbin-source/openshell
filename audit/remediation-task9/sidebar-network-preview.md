# 左侧资源栏与网络仪表盘检查（2026-11-08）

基线 `b5d87bb`，分支 `codex/task9-closeout`。参考本地 release tag `v1.1.6`（`f515f1b`）和 `v1.1.7`（`97b98e2`）的源码。旧版左侧采用 CPU/MEM 竖向胶囊和鲸鱼符号；历史波浪在 MonitorDashboard 中采用 200×40 SVG、1.5px 细折线。本轮按用户确认保留这种折叠显示，并补足网络、磁盘及模拟数据。未运行旧版安装包。

## 最终行为

- 折叠宽度 48px，CPU/MEM 使用旧版 8×56px 胶囊和当前百分比。上、下行分别展示箭头和独立历史曲线，悬停可读速率。磁盘显示占用最高的分区，提示明确分区路径。Docker 入口位于资源指标下方，SVG 组件复用 release 中的 `🐳` 字符；容器工作区共用该组件。
- 展开宽度 256px，保留主机信息和资源、端口、进程、容器分组。运行时长和负载各占一行，长挂载点截断后可悬停查看，容量数字不被挤压。
- NetworkTraffic 统一提供侧栏、折叠栏、监控大屏三个展示模式。展开与大屏采用 Apple 风格的浅色材质、克制边框、清晰排版；速率、单位、累计流量与历史趋势分层展示，两个方向使用同一图表尺度。
- 历史只使用当前会话最近三分钟的有效采样，排序、去重并保留最多 60 个点。不可用区间断开曲线，不伪造 0；真实 0 正常展示，零流量峰值也是 0。图表内部的最小尺度仅避免除零，不替代测得峰值。
- 内存容量与占用遵循 unavailable_fields。采集失败、过期或其他会话的快照不能作为实时指标。监控大屏的内存显示和 CPU/内存历史也遵循这些规则。
- 折叠曲线仅随采样刷新；减少动态效果时停止连续滚动，但新采样仍推进时间轴。折叠宽度与胶囊过渡遵循系统减少动态效果设置。

## 模拟预览

预览地址：`http://127.0.0.1:1422/`，双击“模拟 SSH”，切换侧栏折叠/展开；点击资源监控查看大屏。

在 frontend 目录运行本地启动器：`node E:/Projects/openshell/audit/remediation-task9/web/server.mjs`。它在 HTML 的 IPC 边界注入合成会话、CPU 核心、内存、三分钟网络历史、两块磁盘、监听端口、进程、三个容器及 inspect/logs 数据，随采样周期变化。生产入口没有模拟兜底。未知命令会拒绝；模拟操作只改变页内数据。

模拟 CPU 总占用等于四个核心的平均值，累计网络流量随对应速率积分增长，运行时长单调增长。60 个历史样本的核心平均值、59 个区间的双向累计流量增量及运行时长增量均验证通过。

本地 `window.__WEB_MOCK__.setMonitorScenario(...)` 支持 normal、busy、missing、stale、empty；failNext 可注入下一次采样失败。原始脚本、日志、截图和 JSON 保持 ignored，只提交精选结论。
